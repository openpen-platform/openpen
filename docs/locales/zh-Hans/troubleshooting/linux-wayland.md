# Linux 与 Wayland 支持

OpenPen 可在 Linux 上运行，但属于**有条件支持**，取决于你的显示会话：

- **X11 / Xorg 会话**——完整体验，与 macOS 和 Windows 一致（浮动球、展开/折叠、拖拽吸附、固定、竖向栏）。
- **原生 Wayland 会话**（GNOME，目标版本 46+）——可用但**功能缩减**的体验：以固定、常驻的控制栏取代浮动球。

这是针对合成器限制做出的有意适配，而非未完成的移植。在 Wayland 上，OpenPen 的表现更接近一款务实的屏幕标注工具，而非完整的浮动球 UX。

---

## 我正在运行哪种会话？

```bash
echo "$XDG_SESSION_TYPE"   # → "x11" or "wayland"
```

如需完整体验，请登录 **Xorg** 会话（参见下方的[在 Linux 上获得完整体验](#getting-the-full-experience-on-linux)）。

## 功能支持矩阵

| 功能 | X11 / Xorg | 原生 Wayland（GNOME） |
| --- | --- | --- |
| 绘图叠加层（自由绘制 / 直线 / 形状） | ✅ | ✅ |
| 笔触粗细、颜色、高亮模式 | ✅ | ✅ |
| 浮动球 | ✅ | ❌（以固定控制栏代替） |
| 拖动球 / 吸附到边缘 / 固定 | ✅ | ❌ |
| 折叠为球 / 竖向栏布局 | ✅ | ❌ |
| 控制栏位置 | 跟随浮动球 | 固定在左上角，始终显示 |
| 隐藏控制栏（释放其占用区域） | ✅ | ✅——`Ctrl + Shift + \` 或托盘 |
| 键盘快捷键 | ✅ | ✅——仅限 GNOME |
| 与光标相关的操作（呼出到光标处） | ✅ | ❌ |
| 多显示器 | ✅ | ⚠️ 控制栏位于活动屏幕；不支持跨屏拖动 |

## Wayland 限制详解

在原生 Wayland 会话中：

- **没有浮动球。** 控制栏是固定大小的窗口，钉在左上角且始终显示。你无法拖动它、将其折叠为球、固定它，或切换为竖向布局。
- **控制栏会占用其所在区域。** 由于 Wayland 上无法让控制栏窗口穿透点击，它所覆盖的区域对其下方的应用不可交互。需要这部分空间时，可用 **`Ctrl + Shift + \`**（默认）或托盘菜单隐藏控制栏，并以同样方式再次显示。
- **快捷键仅限 GNOME。** OpenPen 将其开关操作（切换绘图模式、隐藏控制栏）注册为 GNOME 自定义键绑定。默认为 `Ctrl + Shift + A`（绘图模式）和 `Ctrl + Shift + \`（隐藏控制栏）。其他 Wayland 合成器（KDE 等）尚未接入。
- **没有与光标相关的功能。** 依赖全局光标位置的操作（如呼出到光标处）不可用，因为 Wayland 不会向应用暴露全局指针位置。
- **绘图画布按需创建。** 绘图叠加层在进入绘图模式时创建，退出时销毁。已完成的笔触会被保留，但在少数情况下，退出绘图模式时仍在进行中（指针尚未松开）的笔触可能丢失。为避免这种情况，请先完成该笔触（松开指针），再关闭绘图模式。
- **多显示器。** 控制栏位于活动屏幕，无法拖动到其他屏幕。

## 在 Linux 上获得完整体验 {#getting-the-full-experience-on-linux}

如需完整的浮动球 UX，请使用 **Xorg** 会话。在 GNOME 上：

1. 注销。
2. 在登录（GDM）界面，点击你的用户名。
3. 点击右下角的齿轮/设置图标。
4. 选择 **GNOME on Xorg**（或「Ubuntu on Xorg」）。
5. 登录。

OpenPen 会在启动时自动检测会话，无需任何配置。

---

## 为什么存在这些限制

Wayland 合成器有意限制客户端应用的能力，其中若干限制会影响透明、始终置顶的叠加层：

- 应用无法自行定位其顶层窗口，因此 OpenPen 无法放置浮动球，也无法让控制栏跟随浮动球移动。
- 透明窗口无法可靠地实现完全点击穿透，因此控制栏所占区域仍会响应交互。
- 全局光标位置和全局键盘快捷键 不像在 X11 上那样向应用开放，因此与光标相关的操作和通用全局快捷键 不可用（改为使用 GNOME 自身的键绑定机制）。

X11/Xorg 没有这些限制，因此其体验与 macOS 和 Windows 一致。

## 问题反馈

如果 OpenPen 在你的 Linux 环境中的表现与上述说明不符，请提交 GitHub issue 并附上：

1. `echo "$XDG_SESSION_TYPE"` 的输出。
2. 你的桌面环境及版本（例如 GNOME 46）。
3. 你的发行版及版本。
4. 运行环境是真实硬件还是虚拟机。
