# Windows: Transparent overlay shows black background

## 症状

Windows上でOpenPenを実行すると、描画オーバーレイウィンドウ（またはフローティングコントロールバー）が透明ではなく**真っ黒な背景**で表示されます。オーバーレイが画面全体を覆い、デスクトップや他のアプリケーションが見えなくなります。

軽微なケースでは、ボールやバーのエッジ付近に黒いちらつきが見られたり、別のウィンドウが前面に来たときだけオーバーレイが黒くなったりすることがあります。

OpenPenは起動時にこの状態を検出し、問題が見つかった場合は警告バナーを表示します。

---

## 原因

これはElectronプラットフォームの既知のバグ
([Electron issue #40515](https://github.com/electron/electron/issues/40515)) であり、
GPUハードウェアとグラフィックスドライバーの特定の組み合わせに影響します。

Windowsでは、透明な`layered windows`のために、GPUコンポジターがピクセル単位のアルファブレンディングをサポートしている必要があります。一部のGPUドライバー — 特に古いIntelの内蔵GPUドライバーやWindows 10上の一部のAMDディスプレイドライバー — はコンポジターのサポートを報告しますが、誤った出力を生成します。透明領域をデスクトップとブレンドする代わりに、真っ黒 (`RGBA 0,0,0,255`) で塗りつぶしてしまいます。

このバグはドライバーレベルの問題であり、ElectronおよびOpenPenにはプロセス内での確実な修正手段がありません。

---

## 影響を受ける環境

この問題はGPU/ドライバー固有であり、完全には列挙されていません。報告されているパターンは以下のとおりです。

- Intel内蔵グラフィックス (UHD 620、UHD 630、Iris Xe) で、ドライバーバージョンがおおよそ 27.20.x / 2021年より古いもの。
- Windows 10 (20H2以前) 上の一部のAMD Radeon RX 500シリーズドライバー。
- ハードウェアコンポジターを持たないソフトウェアレンダラーを使用する仮想マシンおよびリモートデスクトップセッション (VMware、VirtualBox、基本ディスプレイアダプターを使用したRDP)。

離散型NVIDIAのGPUを搭載し、ドライバーが最新のシステムは通常影響を受けません。

---

## 回避策

以下のオプションを順番に試してください。黒い背景が解消された最初の方法が、そのシステムに適した修正方法です。

### 1. グラフィックスドライバーを更新する（最初に推奨）

GPUベンダーから最新ドライバーを直接ダウンロードしてください — 数ヶ月遅れることが多いWindows Updateではなく:

- **Intel**: https://www.intel.com/content/www/us/en/download-center/home.html
- **AMD**: https://www.amd.com/en/support/download/drivers.html
- **NVIDIA**: https://www.nvidia.com/download/index.aspx

更新後、再起動してOpenPenを再起動してください。

### 2. OpenPenに別のGPUを強制的に使用させる（ノートPC向け）

ノートPCに内蔵GPUと離散GPUの両方がある場合 (例: Intel iGPU + NVIDIA dGPU)、Windowsが内蔵GPU上でOpenPenを実行している可能性があります。離散GPUへの切り替えを試してください。

1. **Windows設定 → システム → ディスプレイ → グラフィックス** (Windows 11) または
   **コントロールパネル → NVIDIAコントロールパネル → 3D設定の管理** (Windows 10) を開きます。
2. アプリ一覧に `OpenPen.exe` を追加します。
3. GPUの優先設定を**高パフォーマンス** (離散GPU) に設定します。
4. OpenPenを再起動します。

### 3. 互換モードで実行する

`OpenPen.exe` を右クリック → **プロパティ → 互換性**:

- **「全画面の最適化を無効にする」** にチェックを入れます。
- **「このプログラムを管理者として実行する」** にチェックを入れます (この操作に問題がなく、他の手順で解決しなかった場合のみ)。

変更のたびにOpenPenを再起動してください。

---

## OpenPenが自動修正しない理由

ハードウェアアクセラレーションの無効化 (`--disable-gpu` フラグ) によって黒背景のバグを防ぐことはできます。しかし、OpenPenはリアルタイム描画アプリケーションであり、なめらかなフリーハンドストローク、筆圧シミュレーション、キャンバスコンポジティングにはハードウェアアクセラレーションが不可欠です。無効化すると深刻なフレームレート低下が発生し、主要な用途でアプリが実用に耐えなくなります。

少数に影響するドライバーのバグを回避するために全ユーザーの描画体験をサイレントに低下させるのではなく、OpenPenは状態を検出して通知します。これにより、根本原因 (ドライバー) に直接対処できます。

---

## 報告

いずれの回避策も解決しない場合は、GitHubのIssueを開き、以下の情報を含めてください。

1. GPUのモデルとドライバーバージョン (**デバイスマネージャー → ディスプレイアダプター →
   対象GPUを右クリック → プロパティ → ドライバータブ** で確認できます)。
2. Windowsのバージョン (スタートメニューから `winver` を実行)。
3. DirectX診断ツールの出力: `Win + R` を押して `dxdiag` と入力し、
   **「ディスプレイ」** タブをクリックします。**「すべての情報を保存...」** をクリックし、
   生成された `DxDiag.txt` をIssueに添付してください (GPUドライバーと機能レベルの詳細が含まれており、バグを特定のドライバーバージョンに特定するのに役立ちます)。

この情報は、新しいドライバーの組み合わせを特定し、上流のElectron修正の進捗を追跡するのに役立ちます。

**Electron上流のIssue:** https://github.com/electron/electron/issues/40515
